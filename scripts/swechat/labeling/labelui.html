Slop Labeling

Target sentence

Rulebook summary (full text)

Slop: the sentence's meaning or truth depends on session context (the conversation or the agent's machine) that a reader of the repository doesn't have. Test: could a developer with the whole repo, who never saw the session, understand and check it?

Slop kinds: refers to the chat or what the user said; narrates how the code changed this session ("now", "used to", "the old…"); facts about the author's machine or one run; measurements from session runs; plan/phase/story references not in the repo.

Not slop: self-contained design reasons ("X instead of Y because…"); references a reader can resolve (repo files, public issue IDs, URLs); plans that are files in the repo; "the user" meaning the software's user; placeholder paths; redundant or AI-sounding but self-contained comments; text copied from a file the agent read.
